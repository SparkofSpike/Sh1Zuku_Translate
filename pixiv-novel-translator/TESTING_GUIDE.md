# 浏览器插件测试指南（零基础版）

> 本指南写给**完全不懂编程**的人。按顺序做就行，不需要安装任何开发工具。

## 你需要准备

- 一台电脑，装有 **Edge** 或 **Chrome** 浏览器（Edge 是 Windows 自带的）
- 从朋友/作者那里拿到插件文件夹 `pixiv-novel-translator`（压缩包 `zip` 也行）

## 第一步：解压插件

如果拿到的是压缩包，右键 → **解压到当前文件夹**。

记住解压出来的文件夹位置（比如 `下载\pixiv-novel-translator`），后面要用。

## 第二步：安装插件（一次性操作）

1. 打开浏览器，在地址栏输入 `edge://extensions`（Chrome 浏览器输入 `chrome://extensions`），回车
2. 打开页面左上角（或左下角）的 **「开发人员模式」** 开关
3. 点击 **「加载解压缩的扩展」** 按钮
4. 在弹出的窗口里，选择刚才解压出来的 **`pixiv-novel-translator` 文件夹本身**（不要选里面的子文件夹），点确定

看到卡片上出现 **"Pixiv Novel Translator"** 就说明安装成功了。如果浏览器提示"开发者模式扩展"，点"仍然使用/保留"即可。

## 第三步：注册账号并生成插件钥匙（API Key）

插件调用翻译功能需要一个"钥匙"，一次搞定，以后不用再弄：

1. 用浏览器打开网站：`http://ad.rainplay.cn:15066`
2. 点右上角 **「注册」**，填用户名、邮箱、密码
3. 弹出一份条约，**往下滚动到底**，勾选"我已了解并同意以上所有内容"，点「同意并注册」
4. 注册成功后点 **「登录」**，进入网站
5. 点右上角 **「个人资料」**，找到 **「插件 API Key」** 一栏
6. 点 **「生成插件 Key」**，然后点 **「复制」**（这串字符很长，复制后先粘到记事本里存着，**关掉页面就看不到了**）

## 第四步：在插件里填入地址和钥匙

1. 点浏览器右上角的扩展图标（拼图🧩图标），找到 **"Pixiv Novel Translator"**，点旁边的图钉📌把它固定到工具栏
2. 点插件图标，在设置里填入：
   - **后端地址**：`http://ad.rainplay.cn:15066`
   - **API Key**：粘贴刚才复制的那串字符
3. 保存设置

## 第五步：开始测试！

1. 打开任意一个 Pixiv 小说页面（浏览器登录 Pixiv 账号效果最佳）
2. 页面右侧会出现插件按钮，点 **「翻译」**
3. 第一次等待约 10~30 秒属正常（AI 正在生成）
4. 翻译完成后，可以切换显示模式：右侧悬浮窗 / 原文下方内嵌对照 / 分页显示

## 常见问题

| 问题 | 解决办法 |
|------|----------|
| 点了翻译没反应 | 刷新一下 Pixiv 页面，再点一次 |
| 一直转圈/超时 | 网络波动，稍等再试；检查第四步的地址和钥匙是否填对 |
| 提示钥匙无效 | 回到第三步，在个人资料页重新生成一个 Key |
| 插件设置改动后不生效 | 到 `edge://extensions` 点插件卡片上的**刷新图标**，然后刷新 Pixiv 页面 |
| 翻到一半断了 | 点插件按钮重新翻译（长文建议用"全文翻译"模式） |

## 遇到解决不了的问题

把以下信息发给朋友/作者，能帮他们快速定位：

1. 浏览器名称和版本（设置 → 关于）
2. 插件设置页的截图（地址和 Key 打码）
3. 翻译时页面出现的报错文字（如果有）
