## What's new

- **Updated the built-in model list** — the site models are now `deepseek-flash` (the merged, natively multimodal model) and `deepseek-v4-pro`. The retired names `deepseek-v4-flash` and `deepseek-v4-flash-vision-exp` no longer appear in the picker, and `deepseek-flash` is labelled as the vision-capable choice.
- **Added a Chinese user guide** — `使用教程.md` now ships inside the extension folder, covering installation, the one-time backend/API-key setup, all three display modes, and the problems users actually run into.
- Manifest and build metadata updated to 1.4.1.
- The release package contains the complete extension, the updater executable, and updater source code.

## Install

Download the zip, extract it, then run `tranShilator-plugin/CheckUpdate.exe`, or load via `edge://extensions` (Developer mode → Load unpacked) and pick the `tranShilator-plugin` folder.
