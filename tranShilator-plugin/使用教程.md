# Pixiv 小说翻译插件 · 使用教程

> 插件名：**Pixiv Novel Translator**
> 支持浏览器：Edge / Chrome（Manifest V3）
> 版本号看弹出窗口底部显示的那一行

这个插件把 Pixiv 上的日文小说直接翻成中文、英文或韩文，译文可以嵌在原文下面逐段对照，也可以放在侧边面板里。

---

## 一、安装

### 方式 A：用更新器安装（Windows，推荐）

1. 到 [Releases](https://github.com/SparkofSpike/Sh1Zuku_Translate/releases/latest) 下载最新的 `tranShilator-plugin-vX.Y.Z.zip`。
2. 解压，运行里面的 **`tranShilator-plugin/CheckUpdate.exe`**。
   它会自动下载最新版并安装到：

   ```text
   %LOCALAPPDATA%\PixivNovelTranslator\tranShilator-plugin
   ```

3. 打开 `edge://extensions`（Chrome 是 `chrome://extensions`）。
4. 打开左下角/右上角的 **开发人员模式**。
5. 点 **加载解压缩的扩展**，选择上面那个 `tranShilator-plugin` 文件夹。
6. 工具栏出现插件图标，安装完成。

> 以后升级只需再运行一次 `CheckUpdate.exe`，它会覆盖到同一目录；之后在扩展页点一次「重新加载」。

### 方式 B：手动加载（其他系统 / 不想用更新器）

1. 下载 release 压缩包并解压。
2. 打开 `edge://extensions`，开启开发人员模式。
3. **加载解压缩的扩展** → 选择解压出来的 `tranShilator-plugin` 文件夹。

## 二、准备：账号与插件 Key

插件翻译时要连你使用的 ShizukuTranslate 后端，得先有一个账号和一个专用的插件 Key。

1. 打开后端网站（例如 `http://154.36.158.104/`），注册并登录。
2. 进入 **「个人」** 页面，完成 **邮箱认证**。
   ⚠️ 未认证的账号**不能**使用翻译功能 —— 网页和插件都一样。
3. 在同一页面找到 **「插件 API Key」** 区块，点 **「生成插件 Key」**。
4. 复制生成出来的 Key（形如 `sk-...`）。
   ⚠️ **只显示一次**，请立刻存好；丢了就重新生成一个。

## 三、首次配置

点浏览器工具栏上的插件图标，会弹出设置窗口：

| 设置项 | 填什么 |
|---|---|
| **后端地址** | 你使用的站点地址，例如 `http://154.36.158.104/`（不要以 `/api` 结尾） |
| **API Key** | 第二步生成的插件 Key |
| **目标语言** | 中文 / English / 한국어 |

填好后配置会自动保存；保存成功后这三项会折叠进顶部的 **「设置」** 按钮里，之后想改再点开即可。

> 若站点需要登录才能访问，请先在浏览器里登录一次该站点。
> 首次翻译时浏览器会弹出「是否允许访问该网站」的请求，**必须点允许**，否则插件无法调用后端。

## 四、开始翻译

1. 打开任意 Pixiv 小说页（网址形如 `https://www.pixiv.net/novel/show.php?id=xxxx`）。
2. 点插件图标 —— 窗口里会提示 **「当前在 Pixiv 小说页面」**。
   （如果显示「请在 Pixiv 小说页面使用」，说明当前标签页不是小说页。）
3. 点 **「翻译当前小说」**。
4. 译文按你选的显示模式出现。

**关于自动翻译**：设置里的 **「自动翻译」默认是开启**的，打开小说页就会自动开始翻译。不想这样的话，把勾去掉，以后手动点按钮。

**几个常用按钮**：

- **重新翻译**：取消正在进行中的翻译并从头再来一遍（译文不满意、或中途改了设置时用）。
- **查看翻译历史**：打开网站的历史记录页，所有翻完的结果都存在那里。
- **提交错误日志**：出错时点它把最近几条错误反馈给开发者。

## 五、显示模式怎么选

弹出窗口里的 **「显示模式」** 有三个选项：

### 1. 原文内嵌对照（默认，推荐）

译文直接插在原文每一段的下方，像双语对照一样读。选中它时下面会多出两个子选项：

- **翻译范围**
  - `只翻译本页`：只翻当前页，翻页后要再点一次。
  - `翻译全篇`：一次翻完整篇，翻页时自动把对应段落的译文填上去，不会重复翻译也不会重复计费。
- **分段方式**
  - `按分段符 <p> 分隔`：常规小说用这个。
  - `<br> 和 <p> 都能分隔`：诗歌、或原文用 `<br>` 换行的作品用这个。

### 2. 侧边面板

译文显示在页面右侧的悬浮窗里，可以拖动位置，缩小后会变成右下角的小胶囊。
**当插件定位不到原文段落时（Pixiv 改版、特殊排版），会自动降级到这个模式。**

### 3. 分页模式（保留 `[newpage]`）

保留 Pixiv 原文里的分页标记，按分页块显示译文。适合结构特殊、需要看到原始分页的作品。

## 六、进阶设置

- **模型**：默认用站方提供的模型；如果你在网站「个人 → 模型配置」里建过自己的配置，下拉框里会一并列出来。
  - `deepseek-flash`：站方默认，**支持看图**。
  - `deepseek-v4-pro`：站方提供的另一个选项（具体能力与计费由站方配置决定）。
- **思考**：勾上后模型会先推理再翻译，**更慢但更准**，术语多、句式绕的作品值得开。
- **附加预设（可多选）**：从网站同步过来的预设词条，比如某部作品的人名/专有名词表，勾上能让译名前后一致。
- **自定义附加 Prompt**：临时补一句要求，例如「人名保留日文原文」「对话用口语」。
- **保存设置**：改动其实会自动保存，这个按钮只是显式确认一遍。

## 七、常见问题

**Q：翻译点不动 / 一直没反应？**
逐项检查：后端地址能不能在浏览器里打开 → API Key 是否有效（无效就在网站重新生成）→ 账号邮箱是否已认证 → 首次翻译弹出的「允许访问该网站」是否点了允许。

**Q：翻译登录限定 / R-18 小说失败？**
先在浏览器里登录 Pixiv，再回小说页翻译。公开小说则不需要登录 Pixiv。

**Q：插件更新了，但页面行为没变？**
两个动作都要做：在 `edge://extensions` 点插件的 **「重新加载」**，然后 **刷新 Pixiv 页面**。少了后者会报 `Extension context invalidated`。

**Q：读了半天没出结果？**
长篇小说的模型预填充可能要几分钟，属正常。期间可以点「重新翻译」取消。

**Q：译文和原文对不上 / 只翻了一部分？**
换用 **侧边面板** 模式看看是否完整；如果面板里是全的、内嵌不全，多半是 Pixiv 页面结构特殊，此时用「`<br>` 和 `<p>` 都能分隔」或改用手动分页更稳。

**Q：会暴露我的模型 API Key 吗？**
不会。插件只持有你自己的「插件 Key」用来调用后端；你在网站里配的模型 Key 不会下发给插件（后端返回时已抹掉预览）。

## 八、更新与反馈

- 插件在浏览器启动时、以及之后每 **6 小时**自动检查一次更新。
- 也可以点弹出窗口底部的 **「检查更新」** 手动检查。
- 命令行方式（需要指定安装目录时）：

  ```text
  CheckUpdate.exe --path <扩展文件夹>
  CheckUpdate.exe --force
  ```

- 出了问题，先在弹出窗口点 **「提交错误日志」**；也欢迎到
  [GitHub Issues](https://github.com/SparkofSpike/Sh1Zuku_Translate/issues) 反馈。
